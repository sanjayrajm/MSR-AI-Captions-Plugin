02

Installation

Follow these steps on Windows for a clean first-time setup.

1

Download the project

Use Download ZIP above or clone the repository.

git clone https://github.com/sanjayrajm/MSR-AI-Captions-Plugin.git
cd MSR-AI-Captions-Plugin
2

Install Python packages

Python 3.12 is recommended.

py -3.12 -m pip install -r requirements.txt
3

Configure Gemini

Copy .env.example to .env and add your API key. Never commit the real key.

GEMINI_API_KEY=your_key_here
4

Install FFmpeg

FFmpeg must be available in your Windows PATH because MSR extracts temporary WAV audio from the Resolve source media.

ffmpeg -version
5

Run MSR AI Captions

py -3.12 app\main.py
6

Install the Resolve script

Keep plugin and app as sibling folders inside the installed MSR-AI-Captions-Plugin folder. Then open Workspace → Scripts → MSR AI Captions in DaVinci Resolve Studio.
